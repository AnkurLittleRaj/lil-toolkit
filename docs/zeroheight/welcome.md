# Little Design System

**By Ankur**

A little system. Room for anything.

A personal, adaptable design system for responsive web applications. Start with SaaS dashboards and settings; carry the same foundations into future products.

## Principles

**Clear by default.** Make the next action easy to understand.

**Space to breathe.** Use generous spacing, focused groups and calm surfaces.

**Adaptable by design.** One visual language across desktop, mobile, light and dark.

## Where to work

Use Figma for design and composition, Storybook for live behavior and component APIs, GitHub for implementation and releases, and this guide for usage decisions.
