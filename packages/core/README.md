# Lil Toolkit

**Little Design System · By Ankur**

A reusable design system for responsive web applications. Built once with Stencil, delivered as native Web Components and generated Angular, React and Vue libraries.

[Figma](https://www.figma.com/design/mjE6UWIjTk1zkJ0F0uonGD) · [Storybook](https://ankurlittleraj.github.io/lil-toolkit/) · [Release setup](docs/releasing.md)

## Packages

| Package                               | Purpose                                                                |
| ------------------------------------- | ---------------------------------------------------------------------- |
| `@ankurlittleraj/lil-toolkit`         | Plain JavaScript/custom elements, tokens, fonts, types and lazy loader |
| `@ankurlittleraj/lil-toolkit-react`   | Generated React bindings with typed props and events                   |
| `@ankurlittleraj/lil-toolkit-angular` | Standalone Angular components and form value accessors                 |
| `@ankurlittleraj/lil-toolkit-vue`     | Generated Vue bindings with `v-model` support                          |

See the registry and deployment status in GitHub Actions. Package names in this README describe the intended public distribution; do not infer that a release exists until its publish workflow has passed.

## Development

Use Node.js 24 (at least 24.15) and npm 11 or newer.

```sh
npm ci
npm run build
npm run storybook
```

```sh
npm test
npm run build-storybook
npx playwright install chromium
npm run test:browser
npm run pack
```

Build order is tokens → Stencil → React → Vue → Angular. Framework proxies are generated by the Stencil output targets, not hand-maintained copies. The lockfile fixes the dependency graph.

## Plain JavaScript

Packages are published **only to GitHub Packages**, not npmjs.org. npm is still the package-manager CLI. Before installing any framework package, add this scope mapping to your application's `.npmrc`:

```ini
@ankurlittleraj:registry=https://npm.pkg.github.com
```

Authenticate to GitHub Packages with a GitHub personal access token (classic) that has `read:packages`. Keep the credential in your user-level npm config, not the repository:

```sh
npm login --scope=@ankurlittleraj --auth-type=legacy --registry=https://npm.pkg.github.com
```

Then install the released package:

```sh
npm install @ankurlittleraj/lil-toolkit
```

```js
import "@ankurlittleraj/lil-toolkit/fonts.css";
import "@ankurlittleraj/lil-toolkit/tokens.css";
import { defineCustomElements } from "@ankurlittleraj/lil-toolkit/register";
defineCustomElements();
```

```html
<lil-button>Create project</lil-button>
<lil-input label="Email address" name="email" type="email"></lil-input>
```

Use `.value`/property assignment for objects and arrays; HTML attributes represent strings. Listen to `lilInput`, `lilChange`, `lilSelect` and `lilNavigate` with `addEventListener`.

## React

```tsx
import { LilButton, LilInput } from "@ankurlittleraj/lil-toolkit-react";
import "@ankurlittleraj/lil-toolkit/tokens.css";
import "@ankurlittleraj/lil-toolkit/fonts.css";

export function Account() {
  return (
    <>
      <LilInput
        label="Email address"
        onLilInput={(e) => console.log(e.detail.value)}
      />
      <LilButton>Save changes</LilButton>
    </>
  );
}
```

## Vue

```vue
<script setup>
import { ref } from "vue";
import { LilInput, LilButton } from "@ankurlittleraj/lil-toolkit-vue";
import "@ankurlittleraj/lil-toolkit/tokens.css";
const email = ref("");
</script>
<template>
  <LilInput label="Email address" v-model="email" /><LilButton
    >Save changes</LilButton
  >
</template>
```

## Angular

```ts
import { Component } from "@angular/core";
import { FormsModule } from "@angular/forms";
import {
  LilInput,
  LilButton,
  TextValueAccessor,
} from "@ankurlittleraj/lil-toolkit-angular";

@Component({
  selector: "app-account",
  standalone: true,
  imports: [FormsModule, LilInput, LilButton, TextValueAccessor],
  template:
    '<lil-input label="Email address" [(ngModel)]="email" /><lil-button>Save changes</lil-button>',
})
export class Account {
  email = "";
}
```

Import the core `tokens.css` and optional `fonts.css` in your global styles. Initial Angular compatibility is v22; React supports v18/19 and Vue supports v3.4.38+ within v3. This is a browser component library; SSR and hydration integrations are not claimed as validated.

## Themes and foundations

Set `data-lil-theme="light"` or `data-lil-theme="dark"` on `html` or a containing element. Without an explicit root theme, the operating system preference applies.

```css
/* Override semantic tokens in your application, rather than component internals. */
:root {
  --lil-accent-solid: #6941d9;
}
```

`tokens/source.json` is the editable source; `npm run tokens` generates CSS and a single DTCG token set containing Light and Dark groups for zeroheight Free. Inter is self-hosted with its SIL OFL notice.

## Components and examples

Buttons, fields, checkboxes, switches, cards, badges, icons, navigation, filters, tabs, sidebar, menu, dialog, toast, data states, metrics, revenue and plan charts, customers and activity. Storybook contains guidelines, live states and separate interactive dashboard/settings examples.

Keyboard support, native form participation, dialog focus containment, reduced motion and chart data tables are implemented. Automated accessibility checks do not replace manual review in your application.

## Delivery

- Every pull request builds the four packages, checks tokens, builds Storybook and runs browser tests.
- `main` deploys static Storybook to GitHub Pages after validation.
- A `v<version>` tag publishes the four packages only to GitHub Packages.
- GitHub workflow artifacts include all four `.tgz` packages.
- [Zeroheight setup](docs/zeroheight/README.md) uses its Free plan, one styleguide and one token set.

GitHub Packages initially publishes packages privately even for public source repositories. Change each package visibility to Public after its first publish. Installing from GitHub Packages requires authentication even for public packages. No npmjs.org publishing job or credential is used.
