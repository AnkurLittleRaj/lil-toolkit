# Little Design System

**By Ankur** · Lil Toolkit · v0.1.0

A little system. Room for anything.

Clean, understated foundations for responsive web applications. Indigo-violet accents, Inter typography, spacious layouts and slightly rounded corners, with light and dark themes.

## Explore

- **Foundations** — color, typography, spacing, accessibility and responsive behavior.
- **Components** — live controls, states, APIs and usage notes.
- **Patterns** — charts, tables, metrics and feedback.
- **Examples** — an interactive SaaS dashboard and settings on desktop and mobile.
- **Integration** — plain JavaScript, React, Angular and Vue installation.

Use the theme toolbar to switch Light and Dark. Every component reads the same semantic CSS tokens. The dashboard includes functioning menus, dialogs, tabs, theme changes and responsive navigation.
